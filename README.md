Waste Classifier Streamlit App
This is a web application to classify waste images into categories like cardboard, glass, metal, paper, plastic, or trash.
It uses a Convolutional Neural Network (CNN) trained on a waste dataset and is built with Streamlit.

Features
Upload any image of waste and receive the predicted class instantly.

Easy to run locally using Streamlit.
